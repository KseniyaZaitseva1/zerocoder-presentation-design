# Визуальная система презентаций
Сдержанный тёмный стиль курса ChatGPT и Codex. Основа — сохранённый скилл и правки этой учебной серии. Приоритет: читаемость, понятная структура, разнообразные учебные объекты.

## Цвет
| Роль | Цвет | Применение |
| --- | --- | --- |
| Фон | #08080B | Основная сцена |
| Основной текст | #F5F4F1 | Заголовки |
| Пояснения | #C9C7D1 | Второстепенный текст |
| Мятный | #8BFFC0 | Рубрика и вывод |
| Сиреневый | #C1A4FF | Понятие, шаг, акцент |

Выделение должно помогать смыслу. Лёгкие градиенты и свечение поддерживают фон, не мешая чтению.

## Типографика
Bahnschrift, системные замены Arial Narrow и Arial. Код — Consolas или читаемый моноширинный шрифт.

Для сцены 1600×900: заголовок 60–64 px, разделитель до 108 px, основной текст 25–29 px, код 23–24 px. Обложку можно уменьшить, если название длинное. Не сжимайте весь текст: разделите мысль на два слайда. Проверяйте межстрочный интервал у крупных слов.

## Сетка и камера
Сцена масштабируется целиком. Поля около 76 px по горизонтали и 60 px сверху. Заголовки обычно ограничены шириной 1060 px.

Верхний правый прямоугольник x=1136–1600, y=0–225 остаётся пустым для камеры. Без текста, иллюстраций, подписей и декоративной рамки. Ниже можно использовать всю ширину.

Заполняйте полезную площадь: избегайте случайных больших пустот и перегруженных мелких блоков.

## Макеты
- Обложка — тема, описание, небольшая композиция внизу справа.
- Эксперт — фото и несколько блоков подтверждённых фактов.
- План — действия и результаты.
- Разделитель — новая тема, пояснение, простой знак.
- Теория — пример с разбором или схема процесса.
- Сравнение — таблица с настоящими различиями.
- Демонстрация — крупный результат с подписями.
- Практика — шаги и проверка слева, один промпт справа.
- Итоги — короткие пункты по содержанию.
- Финал — один вывод и следующий шаг.

## Анимация
Весь слайд появляется за один мягкий переход. Допустимы лёгкий сдвиг, масштабирование и медленное нижнее свечение. Учитывайте prefers-reduced-motion.

Без появления по строкам, кликабельных объяснений и тестов с ответами по нажатию. Кликабельными остаются навигация, источники и необходимые элементы управления.

## Иллюстрации
Реальные скриншоты, схемы, документы и результаты работы. Разные сцены — разные изображения. Не повторяйте одну картинку как три стадии процесса.

Схемы служат конкретной мысли. Подписи остаются внутри своих областей. Числовые графики строятся только по проверенным данным, без декоративных процентов и выдуманных рейтингов.

## Что подтверждено правками пользователя
Тёмный, современный и спокойный стиль. Меньше вычурности. Больше понятной теории. Плашка перед новой темой. Разные макеты. Полезное заполнение пустоты. Практика на одном слайде, подробности отдельно. Свободная зона камеры.

Эти правила относятся к данной серии взрослых учебных презентаций, а не ко всем проектам пользователя.
